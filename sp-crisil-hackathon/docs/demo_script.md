# Demo Script (target: 4:30-5:00)

Setup before judging starts (not part of the timed demo): run the
"Exact run commands" from README.md so `data/signals.jsonl`,
`data/signals_synthetic_demo.jsonl`, and the API are ready. The demo
itself never calls a live news/model API - everything is replay data
already on disk.

**0:00-0:30 - Problem & solution**
"Risk teams can't manually triage every news story and filing. We turn
unstructured text into an explainable risk signal, then show its
concrete effect on a portfolio - end to end, deterministically."

**0:30-1:00 - Start / replay**
Show `GET /signals` (or the dashboard's signal list) populated from the
real GDELT+SEC replay data. Point out: no live API call just happened;
this is the deterministic replay path.

**1:00-2:00 - Risk engine analysis**
Pick one real signal. Walk the fields: entity/ticker, sentiment
(label/score - explicitly polarity, not severity), event type + method
(rule vs zero-shot) + matched_rules, resolved event metadata
(document_count, distinct_publisher_count), and the impact score +
factor breakdown. State plainly: impact score is an **uncalibrated
heuristic**, not a probability.

**2:00-3:30 - Module B stress test**
Switch the dashboard's sidebar toggle to **"Include synthetic
high-impact demo fixture"** and say out loud that this is now the
synthetic, fictional demonstration path. Select the ZZDEMO
REGULATORY_LEGAL signal (impact ~9.46/10). Show: trigger reason,
selected scenario + its stylized assumptions, before/after portfolio
value, the waterfall chart by asset class, and the top loss
contributors table - note ZZDEMO assets dominate via
`direct_issuer_match`, with no arbitrary shock on unrelated issuers.

**3:30-4:15 - Traceability**
Click through from the signal back to: source document/URL, matched
entity, event classification method, resolved event ID, and the asset
stress explanation strings ("Stressed via: direct_issuer_match under
the 'REGULATORY_LEGAL' scenario."). Every number has a stated origin.

**4:15-4:40 - Metrics**
State clearly: 187 automated tests passing (unit + integration);
valuation mechanics checked against hand-computed examples. Note what
is *not* claimed: no real-world predictive accuracy, no calibration
study, no live-model run in this restricted dev environment (verified
instead via injected test doubles).

**4:40-5:00 - Closing impact**
"One pipeline, one signal contract, from raw text to a portfolio
number - fully explainable, fully reproducible, ready for a real model
and a real portfolio next."

## Fallback if anything breaks live
Everything above only reads files already generated by the setup
commands - if a live edit broke something, `git checkout` the repo and
re-run the setup commands; no step depends on network access during
judging.
